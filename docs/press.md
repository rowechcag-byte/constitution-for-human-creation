# Press

## About the project

Constitution for Human Creation is a volunteer-led Colorado civic project inviting everyday people to help shape a public charter for how AI should be governed. It pairs a short set of Foundational Principles with a living constitution that grows through public feedback and the work of professionals in each field. It is not ratified law and does not replace applicable law.
